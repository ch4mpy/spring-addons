spring-addons BFF sample

A stand-in for a single-page application served from the same origin as the BFF. It only uses fetch(): the session cookie carries the identity, the CSRF token comes from the XSRF-TOKEN cookie, and OAuth2 redirections are observed (2xx status + Location header) rather than followed by the browser.
